Worker setup

Folder: working-theory-worker. Public settings are in wrangler.jsonc. The only secrets needed are:

  • ADMIN_TOKEN: a random value of at least 32 characters, stored in Cloudflare and entered only into the approval desk.
  • IDENTITY_SECRET: a separate random value of at least 32 characters. Keep this stable; changing it changes mentor lookup IDs.
  • TURNSTILE_SECRET_KEY: from the managed widget.

After Cloudflare authentication and namespace setup, these commands run from the Worker folder. Secret commands prompt privately. Do not paste values into the command line or this page.

npm ci
npx wrangler secret put ADMIN_TOKEN
npx wrangler secret put IDENTITY_SECRET
npx wrangler secret put TURNSTILE_SECRET_KEY
npx wrangler deploy --dry-run
npx wrangler deploy

Keep SUBMISSIONS_ENABLED false until production checks pass. Set it true to open mentor applications. Add approved essay slugs to both PUBLISHED_TOPICS in the Worker and publishedTopics in the browser configuration to open takes on those essays.
