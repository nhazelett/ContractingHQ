Inject Type
Pick a base inject — it seeds the scenario, attachments, and trainer criteria, all of which you can edit
Each base inject is built around one core skill a contingency contracting officer (CCO) has to demonstrate under pressure. Pick the closest fit, then tailor it in the next steps. Every seeded field stays editable, so the template is a starting point, not a script.
⚡
Urgent Requirement
An urgent buy hits the desk. Tests method-of-purchase selection, funds verification, and price reasonableness under time pressure.
💰
Funding Problem
The purchase request arrives without valid funding. Tests the discipline of never committing the government before funds are certified.
📦
Vendor Performance
A vendor delivers late or nonconforming items on an existing order. Tests inspection, acceptance, remedies, and documentation.
🔎
Questionable Requirement
The requirement has a problem: a named brand, a suspicious split, or a scope issue. Tests requirement validation and customer education.
✉
Possible Unauthorized Commitment
A vendor requests payment for work someone already directed. Tests fact gathering and whether the trainee verifies both elements before concluding anything.
🌎
Host-Nation Vendor
Only local sources can meet the need, and the vendor wants cash. Tests payment method selection and documentation standards abroad.
✎
Custom Inject
Start from a blank frame. You write the situation, tasking, and trainer criteria yourself; the builder handles the format.
