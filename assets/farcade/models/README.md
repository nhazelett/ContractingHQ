# FARCADE model downloads and upload

The professional model is intentionally on the **design/farcade-premium-handheld-2026** branch until approved. The public KTHQ site is not changed.

## Upload the converted model

Upload this binary file here:

`assets/farcade/models/farcade-professional-source.glb`

Use GitHub's **Add file > Upload files** control in this directory, select the GLB (8.3 MB), and commit to **design/farcade-premium-handheld-2026**, **not main**.

Once uploaded, retrieve the file on GitHub by selecting it then **Download raw file**, or use:
https://github.com/nhazelett/ContractingHQ/raw/refs/heads/design/farcade-premium-handheld-2026/assets/farcade/models/farcade-professional-source.glb

## Prototype HTML and ZIP

The conversion package is separate and not yet in the repository. The accompanying interactive preview HTML is ~11 KB and the ZIP ~7.4 MB. Upload them under this directory as `farcade-preview.html` and `farcade-professional-3d-preview.zip` to make them downloadable via GitHub.

The original user-supplied Sketchfab archive is ~171 MB; **do not** try to add it directly to ordinary Git history, since GitHub blocks files over 100 MB. Store it locally or attach it to a GitHub release (with the rights notice).

## Project status

The source archive was inspected and converted in ChatGPT's file container, but **the GLB itself has not yet been pushed to GitHub**. Repository text tools cannot access local binary file bytes. Do not mark the asset as hosted until a GitHub file listing confirms it.
