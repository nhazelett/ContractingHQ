Build the office file cabinet before the exercise starts.

The CCO Office Package Tool is a local browser dashboard that creates realistic mock contract action folders for training. It can build single files, append new actions to an existing office, create BPA/IDIQ masters and orders, export trainee copies, and run QC validation before you hand the drive to students.

Basic setup

  1. Download the ZIP on a personal computer.
  2. Extract the folder somewhere normal, such as Documents.
  3. Open the turnover_tool folder.
  4. Run Install Requirements.bat once if Python dependencies are missing.
  5. Run Start Dashboard.bat.
  6. The local dashboard opens in your browser and writes new packages to the local Outputs folder.

Works without AI

The generator has deterministic templates and data built in. It can create usable mock office packages without an AI account, API key, login, or network call.

Better with optional AI

AI assist can add more variation and a controller-only QA pass. It is useful for broader scenario texture, but the tool still controls PIIDs, folders, amounts, trackers, and validation.

User-owned API setup

If a user wants AI, they should use their own OpenAI API key. Run Setup AI Settings.bat, paste the key, and restart the dashboard. A ChatGPT subscription is not the same as API access.

What AI changes

  • More varied scenarios and descriptions
  • Better scenario-specific details
  • Controller-only QA notes after generation

What AI does not control

  • PIID sequencing and folder structure
  • Funding math and registry links
  • Validation, inject keys, and trainee exports

Privacy note

Do not put real contract information, names, PII, source selection information, CUI, or classified data into prompts. Treat this as a training content generator, not an official records system.
