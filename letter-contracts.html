Letter Contracts

For new contingency contracting officers about to step off the plane. A letter contract authorizes a contractor to start work before final terms are negotiated. The Government commits to a not-to-exceed amount; the parties keep negotiating. It exists because mission timing sometimes will not wait for a definitive contract — and because the file still has to track to a clean closure when it does.

FAR Part 16.6 FAR 16.603 NTE Definitization Subpart 18.2
