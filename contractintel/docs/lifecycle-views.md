# Active and potentially completed portfolios

The default Active / upcoming dataset excludes records whose reported potential final end has passed. Potentially completed is the second dataset, with muted gray rows and an explicit label. This is a planning classification, not evidence of physical completion, acceptance, closeout, or an actual recompete.

Future current PoP dates receive the active label. Past current dates with future potential ends remain potentially ongoing. Missing potential dates, invalid or inconsistent dates, pending details, and unavailable details stay in the active dataset with a review label so unresolved contracts are not hidden. A date equal to today has not passed.

Dataset selection controls register rows, text search, set-aside groups, and CSV exports. Exports include the classification and put the dataset in the filename. Historical fiscal-year totals remain office-wide; upcoming expiration cards return the user to the active dataset.

Tests cover final-end boundaries, options extending beyond current ends, missing/inconsistent dates, loading/unavailable source records, mutually exclusive datasets, and upcoming-first ordering. Shared-folder synchronization remains deferred under the user's explicit instruction to deploy from the working copy and sync later.
